🗺️ Live Ferry Tracking

To enable live ferry tracking, you need a free API key from AISStream.io:

  1. Visit aisstream.io
  2. Sign up for a free account
  3. Get your API key from the dashboard
  4. Open app.js and replace YOUR_API_KEY_HERE with your key

Once configured, you'll see real-time positions of all BC Ferries vessels on the map!
